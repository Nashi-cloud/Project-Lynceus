Installer l'extension

Aucun compte à créer, aucune adresse électronique à donner. L'extension demande sa clé d'accès toute seule au premier lancement.

Ce portail ne distribue pas d'archive pour le moment.

cd extension

2. Charger l'extension dans Chrome

  1. Décompressez l'archive dans un dossier que vous garderez, par exemple Documents/lynceus. Si vous le supprimez, l'extension disparaîtra.
  2. Ouvrez chrome://extensions dans la barre d'adresse.
  3. Activez Mode développeur, en haut à droite.
  4. Cliquez Charger l'extension non empaquetée et choisissez le dossier décompressé.

Ce détour par le mode développeur est le prix de la distribution directe. Nous le disons plutôt que de le cacher : tant que l'extension n'est pas sur le magasin de Chrome, c'est la seule façon de l'installer sans intermédiaire.

3. Obtenir la clé d'accès

{% if inscription_ouverte %}

La page d'accueil de l'extension propose un bouton « Obtenir une clé ». Un clic suffit : elle interroge ce portail, reçoit une clé et l'adresse de l'instance, puis se configure seule.

Ce que contient la clé

Une date d'expiration et un nombre d'analyses par jour. Rien d'autre.

Pas de nom, pas d'adresse électronique, pas d'identifiant de compte, puisqu'il n'y a pas de compte. Ce portail ne conserve aucune trace des clés qu'il délivre : il serait incapable de dire qui a obtenu quoi.

Si le bouton échoue, l'adresse du portail à saisir manuellement dans les réglages est celle de cette page.

{% else %}

Ce portail ne délivre pas de clés d'accès, faute de clé d'émission configurée. Renseignez à la main, dans les réglages de l'extension, l'adresse de l'instance que vous comptez utiliser, ou hébergez la vôtre : une instance personnelle n'exige aucune clé.

{% endif %}

4. Premiers pas

Par défaut, l'extension ne fait rien tant que vous ne le demandez pas : clic droit sur une page, puis « Analyser cette page ». Le badge qui signale les pages déjà connues de l'annuaire est facultatif, et demande explicitement la permission avant de s'activer.

Ce choix vient de la charte : le scan est volontaire, et la vie privée est le réglage d'usine.
