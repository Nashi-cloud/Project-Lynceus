Contester une analyse

Toute analyse est contestable, par n'importe qui, y compris et surtout par l'éditeur du site concerné.

Ce qui se passe ensuite, exactement

Votre contestation est enregistrée dans la base de l'instance avec son motif et son message, et le compteur de contestations devient public : il s'affiche sous l'analyse, pour tout le monde, avant même qu'elle soit examinée.

Elle est ensuite mise à disposition de l'opérateur de cette instance, qui dispose d'un outil de modération : retirer l'analyse, la faire refaire, ou la maintenir en justifiant. Toute décision prise est conservée et auditable.

Un cas se règle sans intervention humaine. Si vous signalez que la page a changé, la prochaine visite produira une nouvelle analyse qui remplacera l'ancienne.

Ce que nous ne promettons pas : un délai. Cette instance est tenue par des personnes, pas par un service client. Si ce délai vous semble déraisonnable pour un droit de réponse, l'auto-hébergement reste ouvert : le code est libre.

Il figure en bas de chaque analyse, dans le panneau de l'extension comme dans l'annuaire public.

Uniquement si vous souhaitez une réponse. Laissez vide pour contester anonymement : c'est traité de la même façon.
