Comment la note est calculée

Les chiffres de cette page ne sont pas recopiés : ils sont lus dans le code qui les applique. S'ils changent un jour, cette page change avec eux.

Quatre dimensions, quatre poids

Le modèle de langage attribue une note de 0 à 100 à chacune de ces quatre dimensions, et justifie chacune. Il ne calcule pas la note globale.

{% for d in ponderations %}
{{ d.libelle }} {{ d.cle }} {{ d.poids }} %
{% endfor %}

La note globale est calculée par le serveur

C'est un point de méthode, pas un détail d'implémentation. Une moyenne pondérée est déterministe et vérifiable : deux personnes qui appliquent la même formule aux mêmes dimensions obtiennent le même résultat. Laisser un modèle de langage produire directement une note reviendrait à rendre le chiffre inauditable.

{% for s in seuils %}
{{ s.grade }}
{{ s.de }} – {{ s.a }}
{% endfor %}

Chaque citation est vérifiée

Un modèle de langage invente parfois des citations. Le serveur refuse donc toute détection dont l'extrait n'est pas retrouvé mot pour mot dans la page analysée, et refuse toute technique absente du référentiel. Ce qui a été écarté est indiqué dans la réponse : la transparence porte aussi sur les erreurs du modèle.
