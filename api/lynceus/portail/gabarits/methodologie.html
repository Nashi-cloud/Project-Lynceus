Quatre dimensions, quatre poids

Le modèle de langage attribue une note de 0 à 100 à chacune de ces quatre dimensions, et justifie chacune. Il ne calcule pas la note globale.

La note globale est calculée par le serveur

C'est un point de méthode, pas un détail d'implémentation. Une moyenne pondérée est déterministe et vérifiable : deux personnes qui appliquent la même formule aux mêmes dimensions obtiennent le même résultat. Laisser un modèle de langage produire directement une note reviendrait à rendre le chiffre inauditable.

{% endfor %}

Chaque citation est vérifiée

Un modèle de langage invente parfois des citations. Le serveur refuse donc toute détection dont l'extrait n'est pas retrouvé mot pour mot dans la page analysée, et toute technique absente du référentiel. Ce qui a été écarté figure dans la réponse : la transparence porte aussi sur les erreurs du modèle.

Une note ne dit pas si un texte est vrai

Elle mesure la façon dont il est construit : sourçage, rigueur, registre, transparence de l'éditeur. Un texte factuellement juste mais écrit à coups de procédés d'urgence obtiendra une note moyenne, et c'est voulu.
